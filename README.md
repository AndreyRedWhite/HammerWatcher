### Описание фильтров

HAMMER_BODY_MAX_FRAC — максимально допустимая доля тела от всего диапазона свечи.
Было «строго»: 0.30 → тело ≤ 30% диапазона.
Если увеличить (0.35–0.45), начнут проходить «не совсем молоты» с потолстевшим телом — это чаще ложняк.
Для точности: держать 0.25–0.33.

HAMMER_WICK_MULT — насколько длинной должна быть «рабочая» тень относительно тела.
2.5 означает: нижняя (для бычьего) ≥ 2.5× тело.
Меньше → больше сигналов, но тоньше граница с обычным «пин-барчиком».
Для точности: 2.4–2.8 (на MOEXF это хороший коридор).

HAMMER_OPP_WICK_MAX_FRAC — максимально допустимая длина противоположной тени относительно тела.
0.6–0.7 «режет» молоты с длинной «шляпой».
Если поставить 0.9, пролезут «крестоподобные» свечи и шум.
Для точности: 0.5–0.7.

HAMMER_EXT_WINDOW — окно, в котором свеча должна быть локальным минимумом/максимумом (признак «выбросили — откупили»).
Меньше окно (3–4) — более либерально, больше (5–7) — строже, меньше ложняка.
Для точности: 5.

HAMMER_EXT_EPS_TICKS — допуск к «почти экстремуму» в тиках.
0.0 — строго самый низ/верх, 1.0–1.5 — позволяет не потерять молот из-за микрошума.
Слишком большой допуск (≥2) ухудшает чистоту.
Для точности: 1.0 (макс 1.5).

HAMMER_VOL_PRCT_MIN — порог объёма по внутридневному перцентилю (насколько объём этой минуты высок для своего времени суток).
0.80 = не ниже 80-го перцентиля — более «сильные» бары.
0.65–0.7 даст больше сетапов, но слабых.
Для точности: 0.8–0.9.

HAMMER_ATR_K_MAX — ограничение «слепых» новостных/панических баров: диапазон свечи ≤ ATR14 × K.
Меньше K — меньше выбросов, но можно потерять «правильные» молоты на резком выкупе.
Для точности: 2.3–2.7 (на 1–5м).

HAMMER_MIN_RANGE_TICKS — минимальная реальная «толщина» бара (в тиках).
Если бар слишком «узкий», даже верный сигнал даст копейки и шумит статистику.
Для точности: 1.0–2.0 тика.

HAMMER_CONFIRM_MODE — тип подтверждения.
classic: следующая свеча закрывается выше high (для BUY) / ниже low (для SELL) молота. Это строже, позже вход, но чище.
pullback: следующая свеча заходит в тело молота. Ранний вход и больше сигналов, но ложняк выше.
Для точности: classic.
